# Ascension Anarchy
A 2D pixel-art, RPG developed using **Unity and C#** for my International Baccalaureate Diploma Programme (IBDP) Computer Science Internal Assessment. The game introduces beginner programming concepts through strategic battles against AI opponents.

## About the Game

The project was designed for a beginner who was interested in programming but found traditional textbook-based learning less engaging. Inspired by Pokémon-style games and strategic combat, the game integrates programming challenges into a virtual fighting tournament.

Players select predefined programming statements and loops to perform attacks and defensive moves. By applying programming syntax and making strategic decisions, players can learn fundamental programming concepts through interactive gameplay.

## Gameplay Features

* **Turn-Based Combat:** Battle AI opponents in a structured system where the player acts before the opponent.
* **Conditional Attacks:** Use correct `IF` statement syntax to execute attacks and gain advantages in combat.
* **Defensive Mechanics:** Use `WHILE` loop syntax to perform defensive moves, including blocking, evading and parrying.
* **Attack Prediction:** Predict opponent actions to increase attack damage and counter defensive strategies.
* **Health and Skill Points:** Manage HP and SP resources to determine which actions can be performed.
* **Programming Challenges:** Answer programming-related questions to recover health and continue battles.
* **Interactive Help System:** Access syntax assistance for combat actions.
* **Optional Tutorial:** Watch a guided video before the first battle to understand the game's mechanics.
* **Retry Mechanic:** Answer a question correctly to recover and resume a battle after reaching zero HP.

## Development Process

The project followed a structured development process:

* **Planning:** Identified the client's learning needs, gathered requirements through interviews and established measurable success criteria.
* **Design:** Planned the combat system, programming challenges, game mechanics, interface and database structure.
* **Development:** Implemented gameplay logic, conditional attacks, defensive actions, resource management and AI opponent behaviour.
* **Testing:** Tested combat mechanics, syntax validation, HP and SP calculations, player inputs and battle progression against the success criteria.
* **Evaluation:** Evaluated the final product against the client's requirements and identified potential improvements.

## My Contributions

### Client Collaboration & System Design
* Conducted initial requirements gathering and planning sessions directly with the client.
* Designed custom user interfaces (UI), character art, and environmental settings tailored to client specifications.

### Object-Oriented Architecture (OOP)
* Architected the core game loop and battle systems in C#.
* Designed the `Battle System` class following the **Single Responsibility Principle**, ensuring each method handles a single, well-defined task to improve maintainability, scalability, and debugging efficiency.

### Data-Driven Game Balance
* Implemented a data-driven architecture separating core application logic from gameplay parameters.
* Stored entity stats, player HP, and question datasets within a database, allowing rapid game balance tuning and testing without source code modifications or recompilation.

### Technical Implementation
* Managed state transitions and character movement via animation controller setups.
* Built robust error-handling pipelines and debugging protocols to ensure application stability.
* Focused on testing to ensure all features are functioning where all Success Criteria are met
